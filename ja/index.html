Kacher が想定する利用シーン

自分のチャンネルとブログ講座とウェビナーポッドキャスト仕事の記録ライブ配信カメラ素材（RAW）
中身

6 つのサブシステムを 1 つの画面に

Kacher はワンボタンのダウンローダーではありません。ダウンロードとキュー、編集、一括変換、配信、プライベートチャット、接続診断を組み合わせたツールです。

01 ⤓

ダウンロードとキュー

自分のソースから形式を選んでダウンロード。数十件のキューを扱えます。

  • 一括ダウンロード、複数選択、形式フィルタ
  • 一時停止、再開、別形式で取り直し
  • 実際のコーデックとサイズをカードに表示
02 ✂

内蔵エディタ 実験的

同じウィンドウにタイムライン、サムネイル、リアルタイムのエフェクトプレビュー。アプリで最も新しい部分で、フィードバックで改善しています。

  • トリム、リップルカット、roll / slip / slide
  • エフェクト、LUT、クロップ、ロゴ消し
  • 字幕とローカル音声認識
03 ⚙

一括変換 一部

数百ファイルを一度に：品質プロファイル、ハードウェア高速化、フォルダ構造の維持、ファイルごとの結果表示。

  • NVENC / QSV / AMF / MF、失敗時は CPU
  • 再エンコードなしの remux、FFV1、ProRes、DNxHR
  • HDR パススルー、BRAW、無音カット
04 ◉

配信の録画

確認済みのライブ配信をその場で録画。時間制限も明示されます。

  • マルチスレッドのフラグメント録画
  • 同一チャンネルのアドレス重複を排除
  • 停止しても書き込み済みは残る
05 ✉

プライベートチャット

端末間の個人・グループ会話、ファイル、音声。サーバーは出会いのメタデータだけを見て、内容は見ません。

  • チャネル暗号化と指紋による鍵確認
  • 最大 8 GiB のファイル、完全性チェック付き
  • 可視性：全員 / 友だちのみ / 不可視
06 ⌁

接続診断

公開ソースから集めたノードを毎回のリクエスト前に検証。どの接続が本当に動くか、応答だけかが分かります。

  • 公開リストと自前ソース、SOCKS と HTTP
  • 最大 500 ノードの一括検証、キャンセル可
  • 実速度で選別、死んだノードを自動整理
編集 · 実験的

結果が見えるエディタ 開発中

サムネイル付きタイムラインと、最終書き出しと同じフィルタチェーンで描くプレビュー。最も新しい部分なので、実験的と明示しています。

2 つのマーク、ここで分割、範囲削除で残りが詰まる、継ぎ目は roll / slip / slide。

エフェクトとキーフレーム

なぜローカルか

クラウドサービスとデスクトップアプリは別物です

他人のコンテンツへのアクセスを売ったり、ファイルを転売したりしません。Kacher は自分の素材を自分の PC で扱うための道具です。

オンライン変換と「クラウド」ダウンローダー

  • ファイルは他人のサーバーに送られ、そこで処理される
  • サービスが制限・拒否・削除することがある
  • リクエストやメッセージの履歴は第三者に保存される
  • 広告やパートナー枠がある
  • 購入後にアカウントがどうなるか不明

Kacher

  • ダウンロード、編集、変換はあなたの PC で
  • 結果はあなたのフォルダに、あなたの管理下で残る
  • メッセージとファイルは端末間で直接やり取り
  • アプリ内に広告もトラッカーもない
  • プランの制限は数字で明示

責任ある利用

Kacher を安全に使うためのルール

この節は Kacher が責任を負う範囲と、アカウント所有者であるあなたに残る範囲を定めます。

自分のコンテンツと許諾されたコンテンツのみ

所有している、ライセンスがある、または明示的な許可を得た素材。

コンテンツ保護の回避はしない

本アプリは DRM を解除せず、技術的保護手段を回避しません。

年齢・地域の制限

ソースの制限は有効なままです。本ツールは回避しません。

ソースサイトの規約

利用規約を確認してください。ダウンロードが禁止されている場合は使わないでください。

表示とライセンス

CC-BY は著者表示が必要、CC-NC と CC-ND は商用利用や改変を制限します。

あなたの責任

ダウンロードした内容と権利の尊重に関する責任は利用者にあります。

制限について正直に

できないことは約束しません。

プロ向けコーデックは一括処理にProRes、DNxHR、FFV1 は一括プロファイルで利用できます。内蔵エディタは FFmpeg のコーデックを使います。
ハードウェア高速化はドライバ次第GPU エンコーダが使えない場合は CPU で続行し、状態に表示します。
AI アップスケールは別途導入同意のうえでエンジンを取得し、チェックサム検証と 1 フレームのプレビューを行います。
音声認識はローカルで高速ではない分離環境の CPU で文字起こしするため、長い動画は時間がかかります。
チャット音声は 1 対 1グループ音声はありません。グループのテキストとファイルは利用できます。
信頼向け設計

データとファイルは分けて扱います

メディアとリンクはあなたの PC、チャットは端末間、支払いデータは決済事業者、ライセンスはアプリのサーバーにあります。

  • ファイルは PC から出ないダウンロード URL と出力ファイルはライセンスサーバーに送られません。
  • チャットは直接サーバーは端末が出会った事実だけを見て、内容は見ません。
  • 鍵は OS の保護下端末の秘密鍵は OS の保護ストレージに保存されます。
  • 決済の秘密は分離事業者の鍵はデスクトップアプリにも拡張にも入りません。
  • ライセンスは端末に紐付け支払い確認後に発行され、移行はアカウントから数クリックです。

インストール前の質問

Kacherは有料プランなしで動作しますか？

はい。無料プランには毎日のダウンロード、標準品質、限定されたストリーム録画が含まれます。

ファイルはどこに保存されますか？

フォルダーを選びます。Kacherは開始前に保存先を表示し、後に実際の出力を検証します。

拡張機能自体がファイルをダウンロードしますか？

いいえ。リンクを収集し、信頼できるデスクトップアプリに渡します。制限と処理はそこで適用されます。

ライセンスを別のPCに移動できますか？

はい。アカウントを開き、リンクされたデバイスセクションからデバイス移転を要求します。

アーカイブを一度つくれば、あとは楽です

Kacher をインストールし、最初のソースを追加して、結果を自分の PC に残しましょう。
