Windows用ダウンロード

Windows 版 Kacher をダウンロード

公式リリースページから、インストーラー、ブラウザ拡張、チェックサムを取得できます。

インストーラーをダウンロード システム要件

Windows で SmartScreen が表示される場合があります。インストーラーは未署名です。実行前に SHA256 を確認してください。

インストール

  1. 1

    KacherSetup-*.exe をダウンロードして実行します。

  2. 2

    初回起動時に FFmpeg、Node.js などのコンポーネントを確認します。

  3. 3

    アカウントでログインするか、Free プランで始めます。

Chrome 拡張

ZIP：解凍し、chrome://extensions の「パッケージ化されていない拡張機能を読み込む」から追加します。
