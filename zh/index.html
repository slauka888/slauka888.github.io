里面有什么

六个子系统，一个窗口

Kacher 不是一键下载器，而是一组互相配合的工具：下载与队列、剪辑、批量转码、直播、私密聊天和连接诊断。

01 ⤓

下载与队列

从你的来源下载，选择格式，队列可容纳数十个任务。

  • 批量下载、多选、按格式筛选
  • 暂停、继续、换格式重新下载
  • 任务卡显示真实编码与大小
02 ✂

内置剪辑 实验性

同一窗口内的时间线、缩略图和实时特效预览。这是应用中最年轻的部分——我们会根据你的反馈持续修复。

  • 裁剪、波纹剪切、roll / slip / slide
  • 特效、LUT、裁切、去水印
  • 字幕与本地语音识别
03 ⚙

批量转码 部分

一次处理数百个文件：质量配置、硬件加速、保留目录结构，并逐个给出结果。

  • NVENC / QSV / AMF / MF，失败回退 CPU
  • 免转码封装、FFV1、ProRes、DNxHR
  • HDR 直通、BRAW、静音剪切
04 ◉

直播录制

确认的直播立即录制，时间上限一目了然。

  • 多线程分片录制
  • 同一频道多地址去重
  • 停止时保留已写入内容
05 ✉

私密聊天

设备之间的私聊、群聊、文件和语音。服务器只看到会面元数据，看不到内容。

  • 通道加密与指纹校验
  • 最大 8 GiB 文件，带完整性校验
  • 可见模式：所有人 / 好友 / 隐身
06 ⌁

连接诊断

从公开来源收集节点，并在每次请求前检查：能看出哪条连接真的可用，哪条只是“有响应”。

  • 公开列表与自有来源，SOCKS 与 HTTP
  • 最多 500 个节点批量检测，可取消
  • 按真实速度筛选，自动清理失效节点

负责任地使用

安全使用 Kacher 的规则

这一节说明 Kacher 负责什么，以及作为账号持有人你需要承担什么。

仅限你自己的与获准的内容

你拥有、已获授权或得到作者明确许可的素材。

不绕过内容保护

应用不解除 DRM，也不规避技术保护措施。

年龄与地域限制

来源的限制依然有效：工具不会绕过它们。

来源网站的规则

请查看使用条款；如果平台禁止下载，请不要用 Kacher 处理。

署名与许可

CC-BY 需要署名；CC-NC 与 CC-ND 限制商用与演绎。

你的责任

对所下载内容及尊重他人权利的责任由用户承担。

如实说明限制

我们不会承诺应用做不到的事。

专业编码在批处理里ProRes、DNxHR 与 FFV1 在批处理配置中提供；内置剪辑使用 FFmpeg 可用编码。
硬件加速取决于驱动GPU 编码器不可用时，工作会转到 CPU，并在状态栏说明。
AI 超分需单独安装引擎在你同意后下载，校验哈希并提供单帧预览。
语音识别本地运行，速度不快转写在隔离环境的 CPU 上执行：长视频需要时间。
聊天语音为一对一没有群组语音频道；群里的文字与文件可用。
以信任为基础

你的数据与你的文件是分开的

媒体文件与链接在你的电脑，聊天在你的设备之间，支付数据在支付服务商，许可证在应用服务器。

  • 文件不离开电脑下载链接与结果文件不会发送到授权服务器。
  • 聊天直连服务器只看到设备相遇，看不到消息与文件内容。
  • 密钥受系统保护设备私钥保存在操作系统的受保护存储中。
  • 支付密钥隔离支付服务商密钥既不在桌面应用，也不在扩展中。
  • 许可证绑定设备确认支付后发放套餐；迁移在账号中几步完成。

安装前常见问题

不付费也能使用 Kacher 吗？

可以。Free 套餐包含每日下载、标准画质和有限的直播录制时长。

文件保存在哪里？

由你选择目录。Kacher 会在开始前显示目标路径，并在完成后验证真实文件。

扩展会自己下载文件吗？

不会。扩展只收集链接并发送到可信桌面应用，由桌面端执行限制和处理。

可以把许可证转移到另一台电脑吗？

可以。在账户的已绑定设备区域申请设备转移。
