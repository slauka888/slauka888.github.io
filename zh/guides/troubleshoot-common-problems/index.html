Kacher 下不了：常见问题与解决办法

按最可能的顺序排查：文件与格式、账号或 cookies、连接与代理，最后再看性能。找到第一个真办法就停，不用全改一遍。

Kacher 不绕过 DRM 或访问限制。如果内容不公开或不能保存，请使用来源导出或已授权的下载。

  1. 先分清症状

    没有格式列表、找不到、清晰度被拦、没声音、导出慢、许可证报错是不同的分支。不要一次重装所有东西。

  2. 检查链接和格式

    自己打开页面确认能加载。如果提示找不到或没有合适格式，用页面规范地址，不要用内部 CDN/HLS 地址。直接录流只用于已确认的直播来源。

  3. 检查 cookies、yt-dlp 和落盘

    cookies 过期就用扩展刷新。403 或格式缺失时先更新 yt-dlp 和 FFmpeg，再重新分析。Kacher 只有在真实输出文件存在时才把任务标为完成。

  4. 检查连接和代理

    传输错误时打开设置 → 代理，用 Test all 或 Blitz。确认当前代理是活的。直连也失败时，可能是站点被你的服务商封了。

  5. 把套餐、清晰度、音频、性能分开看

    格式被套餐拦就降清晰度。只有没声音时换容器或编码，选带音频轨的格式。导出慢时用 Auto GPU 或 CPU，并检查码率配置和分辨率。

  6. 留住失败证据

    保存报错、套餐、版本和 Kacher 日志文件夹里的日志。绝不要发送密码、私钥或完整支付信息。

完成前检查清单

  • 页面自己能打开。
  • 所选清晰度在套餐限制内。
  • 输出文件存在，且不是 .part。
  • 来源和保存权限都清楚。

安装前常见问题

403 或找不到怎么办？

刷新 cookies，更新 yt-dlp/FFmpeg 后重新分析。还不行时，来源可能不公开或不能保存。

为什么没声音？

常常是选了一个只有视频的格式。换容器或编码，选带音频轨的格式。

为什么导出慢？

GPU 编码器、分辨率、编码和码率都会影响速度。检查 GPU，用 Auto，并先拿一个短文件试。
