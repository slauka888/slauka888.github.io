Télécharger Kacher pour Windows

Installateur, extension de navigateur et empreintes depuis la page officielle des versions.

Télécharger l’installateur Configuration requise

Windows peut afficher SmartScreen : l’installateur n’est pas encore signé. Comparez le SHA256 avant de l’exécuter.

Installation

  1. 1

    Téléchargez KacherSetup-*.exe et lancez l’installateur.

  2. 2

    Au premier démarrage, l’application vérifie FFmpeg, Node.js et les autres composants.

  3. 3

    Connectez-vous ou commencez avec l’offre Free.

Extension Chrome

ZIP : décompressez puis chargez-la via chrome://extensions → « Charger l’extension non empaquetée ».
