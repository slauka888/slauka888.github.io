Live recording

How to record your own live stream or webinar

Use Kacher for streams you own or have permission to record. The app treats a confirmed live address differently from a normal video page: it records the stream while it plays and writes the result into the Streams folder.

Kacher does not record the first stream it sees on an ordinary video page. When media fragments appear inside a normal video page, the app goes through analysis instead; an extension-sent link is treated as live only when the source is a confirmed live stream.

  1. Check the plan's stream minutes first

    Stream recording uses your plan quota rather than being unlimited by default. Open the plan limits page before the event so you know how much live time remains.

  2. Start from the live page, not from a video page

    Paste the live address or send the selected stream link from the browser extension. Kacher records from the live edge, so start early if you need the beginning of the event.

  3. Watch the stream in the stream panel

    The stream panel shows that the recording is active. It also shows already-downloaded size and provides stop and save controls for the live recording.

  4. Stop when you have what you need

    Use Stop to end the session. The part that has already been recorded remains as a playable file in the Streams folder; keep it for editing or archive.

  5. Check the file before you close Kacher

    Open the recorded file and verify duration, audio and picture. A stopped live recording should remain a finished file rather than a .part file beside it.

What to check before you call it done

  • The plan still has stream minutes available.
  • The source is a confirmed live stream, not a normal video page.
  • The Streams folder contains a playable file after Stop.
  • You have permission to record and keep the event.

Questions before you install

Will Kacher record the beginning if I start late?

No. Live recording starts from the live edge, so a late start can miss the earlier part of the event.

Does a video-on-demand recording use the live path?

No. A VOD or ordinary video should go through normal analysis and download; only a confirmed live stream uses the live recorder.

What happens if I stop the recording?

The already-recorded part stays in the Streams folder as a playable file. That is the file to verify and archive.
