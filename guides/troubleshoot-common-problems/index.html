Kacher download not working: common problems and fixes

Start with the most likely causes in this order: file and format, account or cookies, connection and proxy, then performance. Stop after the first real fix — you do not need to change everything.

Kacher does not bypass DRM or access restrictions. If a source is not public or cannot be saved, use an exported or permitted download.

  1. Separate the symptom

    No format list, 'not found', blocked quality, missing audio, a slow export and a license error are different branches. Do not reinstall everything at once.

  2. Check the link and format

    Open the page yourself and confirm it loaded. If analysis says 'not found' or 'no suitable formats', use the canonical page address, not an internal CDN/HLS address. Direct stream recording is only for confirmed live sources.

  3. Check cookies, yt-dlp and destination

    If cookies expired, refresh them through the extension. For 403 or missing formats, update yt-dlp and FFmpeg first, then re-analyze. Kacher marks a task done only when a real output file exists.

  4. Check connection and proxy

    For transport errors, open Settings → Proxy and use Test all or Blitz. Check that the active proxy is alive. If direct connection also fails, the site may be blocked by your provider.

  5. Separate plan, quality, audio and speed

    If a format is blocked by the tariff, lower the quality. If only the audio is missing, switch container or codec and choose a format with a combined audio track. If the export is slow, use Auto GPU or CPU and check the bitrate profile and resolution.

  6. Keep failure evidence

    Save the visible error, plan and version, plus the log from the Kacher logs folder. Never send passwords, private keys or full payment credentials.

What to check before you call it done

  • The page opens by itself.
  • The chosen quality is within the plan limit.
  • The output file exists and is not a .part file.
  • The source and save permission are clear.

Questions before you install

What should I do with a 403 or 'not found'?

Refresh cookies, update yt-dlp/FFmpeg and re-analyze. If it persists, the source may not be public or may not be saveable.

Why is there no audio?

Often a video-only format was chosen. Switch container or codec and choose a format with an audio track.

Why is the export slow?

GPU encoder, resolution, codec and bitrate all affect speed. Check the GPU, use Auto and test one short file.
