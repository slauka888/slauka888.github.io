Installer herunterladen Systemanforderungen

Windows zeigt möglicherweise SmartScreen: Der Installer ist noch nicht signiert. Vergleichen Sie vor dem Start die SHA256.

Installation

  1. 1

    Laden Sie KacherSetup-*.exe herunter und starten Sie den Installer.

  2. 2

    Beim ersten Start prüft die App FFmpeg, Node.js und die übrigen Komponenten.

  3. 3

    Melden Sie sich an oder starten Sie mit dem Free-Tarif.

Chrome-Erweiterung
