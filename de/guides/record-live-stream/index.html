So zeichnen Sie Ihren eigenen Livestream oder Ihr Webinar auf

Verwenden Sie Kacher für Streams, die Ihnen gehören oder für die Sie eine Aufnahmeerlaubnis haben. Eine bestätigte Live-Adresse wird anders behandelt als eine normale Videoseite: Kacher zeichnet den Stream während der Wiedergabe auf und schreibt ihn in den Streams-Ordner.

Kacher zeichnet nicht den ersten Stream einer normalen Videoseite. Erscheinen Medienfragmente innerhalb einer normalen Videoseite, läuft die Analyse; ein Link aus der Erweiterung gilt nur bei einem bestätigten Livestream als live.

  1. Zuerst die Streamminuten des Tarifs prüfen

    Stream-Aufnahme verbraucht Ihr Tarifkontingent und ist nicht standardmäßig unbegrenzt. Öffnen Sie vor dem Event die Tariflimits, um zu sehen, wie viel Live-Zeit noch bleibt.

  2. Von der Live-Seite starten

    Fügen Sie die Live-Adresse ein oder senden Sie den Stream-Link aus der Browser-Erweiterung. Kacher nimmt vom Live-Rand auf; starten Sie früh, wenn Sie den Anfang brauchen.

  3. Im Stream-Bereich beobachten

    Der Stream-Bereich zeigt die laufende Aufnahme. Dort sehen Sie die bereits geladene Größe und die Aktionen Stopp und Speichern.

  4. Stoppen, wenn Sie genug haben

    Mit Stopp beenden Sie die Sitzung. Der bereits aufgezeichnete Teil bleibt als abspielbare Datei im Streams-Ordner.

  5. Datei vor dem Schließen prüfen

    Öffnen Sie die Aufnahme und prüfen Sie Dauer, Ton und Bild. Eine gestoppte Live-Aufnahme sollte eine fertige Datei bleiben, keine .part-Datei daneben.

Vor dem Fertigstellen prüfen

  • Im Tarif sind noch Streamminuten frei.
  • Die Quelle ist ein bestätigter Livestream, keine normale Videoseite.
  • Nach Stopp liegt im Streams-Ordner eine abspielbare Datei.
  • Sie haben die Erlaubnis, das Event aufzunehmen und zu behalten.

Fragen vor der Installation

Wird der Anfang aufgenommen, wenn ich spät starte?

Nein. Die Aufnahme beginnt am Live-Rand, daher kann ein später Start den Anfang verpassen.

Läuft ein VOD über denselben Weg?

Nein. VOD oder normale Videos laufen über Analyse und Download; nur bestätigte Livestreams nutzen den Live-Recorder.

Was passiert beim Stoppen?

Der bereits aufgezeichnete Teil bleibt als abspielbare Datei im Streams-Ordner. Diese Datei prüfen und archivieren.
