So speichern Sie Ihr eigenes Video oder Ihren Kanal

Verwenden Sie Kacher für Material, das Ihnen gehört oder für das Sie eine Speichererlaubnis haben. Fügen Sie die Seiten- oder Video-Adresse ein, lassen Sie sie analysieren und wählen Sie das benötigte Format.

Kacher entfernt kein DRM und umgeht keine Zugriffsbeschränkungen. Wenn die Quelle kein herunterladbares Format liefert, nutzen Sie stattdessen eine Datei aus dem Export der Quelle.

  1. Seite oder Video-Adresse einfügen

    Öffnen Sie Kacher, fügen Sie die Adresse in das URL-Feld ein und klicken Sie auf Analysieren. Bei mehreren Links tragen Sie einen pro Zeile ein. Kacher zeigt Titel, Dauer, Kanal und Anzahl der gefundenen Formate.

  2. Video oder Archivliste erkennen

    Kanal, Playlist oder lange Listen brauchen länger als ein einzelnes Video. Fügen Sie die benötigten Adressen hinzu und starten Sie die Analyse einmal. Danach steht jedes Element einzeln in der Warteschlange.

  3. Format nach Verwendungszweck wählen

    Wählen Sie Video- und Audio-Optionen für die gewünschte Wiedergabe oder Bearbeitung. Liegt ein Format über Ihrem Tariflimit, zeigt Kacher es als blockiert statt es still zu ersetzen.

  4. Ausgabeordner vorher festlegen

    Wählen Sie den Speicherordner und prüfen Sie den Dateinamen vor dem Start. Eine klare Ordnerstruktur verhindert später ein unübersichtliches Archiv.

  5. Aufgabe starten und beobachten

    Warteschlange und Formatdialog zeigen den gewählten Codec, Container und die Ausgabe. Bei einem Abbruch starten Sie die Aufgabe aus der Zeile neu; aktualisieren Sie auf Aufforderung die Browser-Cookies.

  6. Echte Datei prüfen

    Eine Aufgabe gilt erst als fertig, wenn Kacher eine tatsächliche Ausgabedatei findet. Öffnen Sie sie, prüfen Sie Dauer und Ton und legen Sie sie dann ins Archiv. Eine .part-Datei bedeutet: nicht fertig.

Vor dem Fertigstellen prüfen

  • Nach der Analyse erscheint die Formatliste.
  • Die gewählte Höhe überschreitet das Tariflimit nicht.
  • Im Ausgabeordner liegt eine fertige Mediendatei, keine .part- oder Zwischenfragmente.
  • Sie haben das Recht, den Inhalt zu speichern und wiederzuverwenden.

Fragen vor der Installation

Was, wenn das gewünschte Format nicht verfügbar ist?

Wählen Sie das nächste verfügbare Format auf oder unter dem Tariflimit. Kacher ersetzt ein angefordertes höheres Format nicht still.

Kann ich mehrere Links auf einmal hinzufügen?

Ja. Einen Link pro Zeile einfügen und analysieren. Lange Listen brauchen länger; Stopp beendet die Warteschlange.

Wohin geht die fertige Datei?

In den von Ihnen gewählten Speicherordner. Kacher markiert die Aufgabe erst als fertig, wenn die echte Datei existiert.
